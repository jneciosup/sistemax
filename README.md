Hola# Sistema X

Proyecto web desarrollado en PHP y MySQL.

## Requisitos Previos

- [XAMPP](https://www.apachefriends.org/es/index.html) (PHP, Apache y MySQL)
- Git

## Instalación y Configuración

1. **Ubicación del proyecto:**
   Asegúrate de que la carpeta del proyecto (`sistemax`) esté ubicada dentro del directorio público de tu servidor local. Si usas XAMPP, la ruta debe ser algo como:
   `E:\PROGRAMAS\Xampp\htdocs\sistemax`

2. **Configuración de la Base de Datos:**
   - Asegúrate de que los servicios de Apache y MySQL estén corriendo en tu panel de XAMPP.
   - Edita tu archivo `.env` y configura los parámetros de conexión a la base de datos (usuario, contraseña, nombre de la base de datos).

3. **Ejecutar el proyecto:**
   - Abre tu navegador web e ingresa a: `http://localhost/sistemax`

4. **Ingresar al sistema:**
   - Usuario: admin
   - Contraseña: [PASSWORD]

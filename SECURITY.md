# Security Policy

## Supported Versions

We currently provide security updates for the following versions of SistemaX:

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within SistemaX, please send an e-mail to the maintainer team. All security vulnerabilities will be promptly addressed.

Please do NOT report security vulnerabilities via public GitHub issues. Instead, contact us privately so we can patch the issue before it is publicly disclosed.
